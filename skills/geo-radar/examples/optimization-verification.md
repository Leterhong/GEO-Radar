# Example: optimization before/after

## Flow

1. Baseline task and retest task must use the same brand and question set.
2. Record the optimization event/page URL in GEO Radar.
3. Compare with `geo_compare_rounds` or the web comparison page.
4. For each changed number, report numerator/denominator and sample size.
5. Check whether the optimized URL actually appears in the new evidence.

## Safe wording

```text
Observed: brand mention rate moved from 5/10 to 6/10 after the recorded change.
Not proven: this does not establish that the change caused the movement.
Other factors: search index, ranking, query wording and time can all affect results.
```
